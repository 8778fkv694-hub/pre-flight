# Pre-flight V2 · 批次 B：执行路由与交接契约

状态：实施中（未验收）。批次 A 已合并；本批次不修改基本法 L1、不改变已确认 Intent，也不新增常驻服务。

## 目标与范围

- **PF-01：风险与工作量双轴路由**。Lite/Standard/Strict 是证据和执行深度，不是批准等级；任何档位均不能降低授权、基本法或必要的验收。
- **PF-06：差异化意图确认**。复用已有已确认 Intent，只有目标、范围、成功标准或关键约束的实质变化才生成候选；普通缺陷修复在已确认 Spec 内直接执行并保留证据。
- **PF-07：跨 Agent 交接契约**。对外部 Agent/宿主交接使用可读、可测试的最小记录，不替换项目内部原生通讯。
- **PF-08：证据来源分级**。区分原始执行证据、可追溯报告、人工/模型推断，不能用低级证据冒充真实运行。

## 路由决策（两轴，取更严格者）

| 轴 | Lite | Standard | Strict |
|---|---|---|---|
| 复杂度 | 单点、可回滚、已知复现 | 多文件、跨模块或有迁移影响 | 架构/接口/权限/不可逆影响 |
| 影响 | 本地隔离、无外部副作用 | 内部用户、共享测试环境 | 生产、真实用户/数据、外发、费用、安全 |
| 最小记录 | 同一工作项含目标/变更/验证/恢复 | WP→Spec→Case→实现证据 | 以上全部 + 风险清单、独立复核、回滚/授权记录 |

未知影响时暂按 Strict **评估**，不代表自动授权执行。档位可随证据调整，降低必须记录理由；与安全/授权边界冲突时以基本法为准。

## 意图判定

1. 当前正式 Intent 是否有可回查的复述及人的确认？没有则只能调查、候选设计，不能冒充已确认目标。
2. 本次输入是否改变服务对象、目标、范围、成功标准或关键约束？是 → 候选差异 + 影响分析 + 人确认。
3. 是否只是已确认 Spec 内的实现、测试、修复、文档或性能优化？是 → 不重复请求 Intent 确认，执行仍受具体权限限制。
4. 是否变更规则/授权？先执行收紧/停止，扩大需单独授权；L1 走基本法修正。
5. 混合/不明：暂停冲突部分，保留已完成工作，提问澄清。避免把“继续”当成新的确认。

## 交接记录（外部 Agent/跨会话）

采用 Markdown 工作包与可选 JSON 结构化交接。最小字段：
- `handoff_id`、`created_at`、`from_agent`、`to_agent`、`task_id`；
- `intent_ref`（ID/版本/确认依据）、`spec_ref`（ID/版本/条款）、`plan_wp_id`；
- `scope`、`allowed_actions`、`forbidden_actions`、`write_set`、`shared_resources`；
- `implementation_ref`、`environment`、`verification`（PASS/FAIL/SKIP/NOT_RUN + 原始证据位置）；
- `pending_decisions`、`next_action`、`resume_point`、`side_effect_state`。

接收方必须先核对当前代码/环境/授权与交接记录是否一致。交接文件不是权限凭证；接收方不能从发送方的文字推断获得更高权限。副作用状态未知时只读对账，不重试。并行写集合冲突时先协调，不依赖 worktree 隔离共享设备。

## 证据等级与不跨层替代

| 等级 | 证据 | 可支持的声明 |
|---|---|---|
| E0 | 原始可回查执行记录、命令/退出码、构建/提交身份、环境、截图或回读 | 在记录的精确环境/版本下实际观察到的行为 |
| E1 | 引用 E0 的测试报告、CI 汇总、可复现步骤 | 被引用样本与环境的汇总结论 |
| E2 | 静态检查、代码审阅、文档与模型推理 | 静态符合性或候选判断，不能声称真实交互/部署已验 |
| E3 | 未验证陈述、转述、示例或估算 | 假设/待核实，不能作为通过证据 |

证据等级不是单一“可信分数”；E0 也只证明其观察范围，不能从一个样本推广到全平台。任何 PASS 必须带测试 ID、版本、环境和可定位证据；SKIP/NOT_RUN 不算 PASS。

## 本批次验收

- 路由覆盖 Lite/Standard/Strict 与未知影响；低风险不被强制创建整套文档。
- 既有 Intent 的缺陷修复不重复索取目标确认，实质变更必须重新确认。
- 交接覆盖恢复点、权限、共享资源、未知副作用与未验事项。
- 证据等级不会让静态审查冒充运行测试。
- 新增文档与可选检查不得强制迁移旧项目；不得修改基本法已冻结条款。
