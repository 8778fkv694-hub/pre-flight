## Hard limitations

1. Inputs were **manually structured** by the benchmark; no LLM performed semantic interpretation, tool discovery, or autonomous selection.
2. No real external Agent host, authorization service, multi-model session, UI operation or side-effect replay was involved.
3. The original `v2-batch-c-scenarios.json` **remains NOT_RUN** as an autonomous Agent behavior benchmark. Do not change that status or claim an LLM success rate of 100%.
4. Runner did not report model latency, token usage or cost; those figures are unavailable.

## Reproduce

`python3 pre-flight/benchmarks/run_tool_benchmark.py` from repository root. The script returns nonzero when any case fails; the CI artifact retains full observed values.

**Recommendation:** keep a separate Agent-host evaluation tier with a pinned model, isolated runtime, repeated trials, raw tool trace and explicit rubric before claiming behavioral adherence.
